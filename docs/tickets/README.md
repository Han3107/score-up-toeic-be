# Tickets & Bugs Directory

Thư mục lưu trữ các design documents, feature tickets và bug reports của dự án.

## Cấu trúc

```
docs/
├── tickets/          # Design documents & feature tickets
│   └── TICKET-001-structured-logging.md
├── bugs/             # Bug reports & investigation notes
│   └── (chưa có)
```

## Quy ước đặt tên

### Tickets
- **Format**: `TICKET-<ID>-<short-description>.md`
- **ID**: Số thứ tự 3 chữ số, tăng dần (001, 002, 003, ...)
- **Ví dụ**: `TICKET-001-structured-logging.md`, `TICKET-002-rate-limiting.md`

### Bugs
- **Format**: `BUG-<ID>-<short-description>.md`
- **ID**: Số thứ tự 3 chữ số, tăng dần (001, 002, 003, ...)
- **Ví dụ**: `BUG-001-auth-token-expired.md`, `BUG-002-upload-timeout.md`
